# Reports

This directory stores synthesis documents, reporting templates, and forward-looking research outputs.

## Synthesis Documents

- [`research-synthesis.md`](research-synthesis.md): current end-to-end synthesis of the research cycle.
- [`comparative-analysis.md`](comparative-analysis.md): comparison framework for optimization strategies.
- [`final-cycle-summary.md`](final-cycle-summary.md): cross-benchmark summary for the completed local first-cycle run.
- [`industry-scenarios.md`](industry-scenarios.md): deployment scenarios that ground the framework in realistic operations.
- [`practitioner-guidance.md`](practitioner-guidance.md): practical guidance for cost-efficient AI usage.

## Special Topics

- [`healthcare-bio-ai-special-topic.md`](healthcare-bio-ai-special-topic.md): applies the cost-taxonomy, skill-domain, and MIT-SDM-lens frameworks to healthcare, hospital, and pharmaceutical AI. Maps six healthcare-bio scenarios (ambient scribing, imaging second reader, CDS / sepsis alerting, prior authorization, drug discovery, clinical trial protocol design) onto the existing framework, extends the compliance-overlay and lifecycle layers with sector-specific additions, and illustrates an FMEA AP analysis for scribing hallucination. Evidence base: [`../references/healthcare-bio-ai-evidence-2026.md`](../references/healthcare-bio-ai-evidence-2026.md).
